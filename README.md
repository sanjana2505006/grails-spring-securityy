# grails-spring-security

Sample application for the **Securing Grails Applications with Spring Security Core** Grails guide (Grails 8).

The `initial/` and `complete/` sample apps and the full README are added via pull request against the `grails8` branch.

Guide prose lives on [grails.apache.org/guides](https://grails.apache.org/guides/) in [apache/grails-static-website](https://github.com/apache/grails-static-website) under `guides/grails-spring-security/v8/`.
